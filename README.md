# دومينز | منصة مجتمعية متنقلة

عرض تقديمي تفاعلي (تصوّري) لفكرة الكارافان المتحرك لدومينز، انطلاقاً من ساحة التحرير في حلب.

## المحتوى
- **الكارافان | فكرة الحضور:** خط السير، الكارافان المتحرك، مكوّناته، أوضاع التشغيل الأربعة، والتنفيذ المرحلي.
- **الأنشطة | ماذا سنفعل؟:** 5 محاور و19 فكرة.

## الملفات
- `index.html`: صفحة العرض
- `css/style.css`: التنسيق
- `js/main.js`: التبويبات والتفاعلات
- `assets/img/`: صور الكارافان والساحة والبدائل (WebP) والأيقونة
- `assets/fonts/`: خط Tajawal محلياً (يعمل بدون إنترنت)
- `render.yaml`: إعداد النشر على Render

## التنقل
- السكرول أو الأسهم ↑ ↓ بين الشاشات، وكل شاشة تملأ الشاشة.
- `1` و`2` للتبديل بين التبويبين.
- ← → داخل الشاشة: المكوّنات، أوضاع التشغيل، أفكار كل محور، وصور معاينة البدائل.

## النشر على Render
في Render اختر **New > Blueprint** واربط هذا المستودع، فيقرأ `render.yaml` وينشر الموقع كموقع ثابت.

> العرض تصوّري: المقترحات قابلة للتطوير ولا تمثّل تجهيزات منفّذة أو قرارات نهائية.
