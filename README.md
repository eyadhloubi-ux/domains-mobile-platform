# دومينز | منصة مجتمعية متنقلة

عرض تقديمي تفاعلي (تصوّري ومسودة اقتراح) لفكرة الكارافان المتحرك لدومينز، انطلاقاً من ساحة التحرير في حلب.

## التبويبات
1. **الكارافان | فكرة الحضور:** خط السير، الكارافان المتحرك، مكوّناته، أوضاع التشغيل، وتوزيع الكارافان والخيام في الساحة.
2. **الأنشطة | ماذا سنفعل؟:** ثلاثة أقسام فرعية: أنشطة دورية (5 محاور بقوائم منسدلة)، رزنامة الأنشطة الدورية (شهر نموذجي)، وأنشطة استثنائية مع الأيام العالمية والمواسم.
3. **المالية | التكاليف المتوقعة:** التكاليف التشغيلية الشهرية بالحد الأعلى، ومصادر الطاقة، وأفكار إيرادات على الهامش.

## الملفات
- `index.html`: صفحة العرض
- `css/style.css`: التنسيق
- `js/main.js`: التبويبات والتفاعلات
- `assets/img/`: الصور (WebP) والأيقونة
- `assets/fonts/`: خط Tajawal محلياً (يعمل بدون إنترنت)
- `render.yaml`: إعداد النشر على Render

## التنقل
- السكرول أو الأسهم ↑ ↓ بين الشاشات، وتنتقل تلقائياً للقسم التالي في النهاية.
- `1` `2` `3` للتبويبات الرئيسية.
- ← → داخل الشاشة: المكوّنات، أوضاع التشغيل، أيام الرزنامة، والأنشطة المنسدلة.

## النشر
- **Render:** New > Blueprint واربط المستودع.
- **GitHub Pages:** Settings > Pages > Deploy from a branch > main / root.
